プライバシーポリシー

最終改定日：2026年10月11日（会員登録導線の計測を追加）

サケノツマミ（以下「当サービス」）は、お酒の種類に合うつまみのレシピを紹介する無料のWebサービスです。
当サービスの運営者（以下「運営者」）は、個人情報の保護に関する法律その他の関係法令を守り、利用者の情報を次のとおり取り扱います。

1. 取得する情報

種類内容取得する場面
アカウント情報メールアドレス。Googleでログインした場合は、Googleアカウントの識別子・表示名・プロフィール写真のURL。パスワードは使いません。会員登録・ログイン
保存データ保存したレシピと、保存した日時レシピを保存したとき
お問い合わせお問い合わせの種類・内容、メールアドレス、お名前（入力した場合のみ）、送信日時お問い合わせフォームから送信したとき
会員登録導線の記録会員登録の案内を見た・ボタンを押した・登録が完了した、という段階と日時だけ。メールアドレスなど個人を特定する情報は含みません会員登録の案内を見たとき・ボタンを押したとき・登録が完了したとき
アクセス情報IPアドレス、ブラウザの種類、閲覧日時など、ページを配信するサーバーが自動で記録する情報ページを開いたとき

お問い合わせの内容と、会員登録導線の記録は、Cloud Firestore（下の4.）に保管します。
読めるのは運営者だけで、送った本人を含め、ほかの利用者が読むことはできません。

次の情報は、利用者の端末（ブラウザのローカルストレージ）にだけ保存します。
運営者は直接見ることができず、ブラウザの設定からいつでも削除できます。

  • sakenotsumami.emailForSignIn：メールでログインするときに、リンクを開くまで一時的に覚えておくメールアドレス
  • sakenotsumami.emailForSignInContext：メールでの会員登録が、どの案内から始まったかを一時的に覚えておく記録（会員登録導線の計測用）
  • sakenotsumami.pendingSave：ログイン前に押した保存を、ログイン後に反映するための記録
  • sakenotsumami.installDismissed：「ホーム画面に追加」の案内を閉じた、または追加した日時。案内を何度も出さないための記録

2. 利用目的

  • 会員の認証と、保存したレシピを複数の端末で表示するため
  • お問い合わせに対応するため
  • 不正な利用を防ぎ、サービスを安全に運営するため
  • サービスの改善のため（アクセス数などを、個人を特定しない形で集計します）

この目的を超えて利用する場合は、あらかじめ利用者の同意を得ます。

3. 第三者への提供

法令に基づく場合などを除き、利用者の同意なく個人情報を第三者に提供しません。
取得した情報を販売することはありません。

4. 利用している外部サービス

サービス提供事業者役割
Firebase Authentication / Cloud FirestoreGoogle LLCアカウントの認証、保存データとお問い合わせの保管
Cloudflare Workers / Cloudflare Web AnalyticsCloudflare, Inc.ページの配信、アクセス状況の集計（Cookieを使わず、個人を特定しない形）
Google Fonts / jsDelivrGoogle LLC ほか書体・アイコンの配信

これらのサービスの利用に伴い、情報が日本国外のサーバーで取り扱われる場合があります。
各サービスでの情報の取り扱いは、それぞれの事業者のプライバシーポリシーに従います。

5. 安全管理

  • 通信はすべて暗号化（HTTPS）しています。
  • 保存データは、ログインした本人だけが読み書きできるよう、アクセスを制限しています。
  • お問い合わせと、会員登録導線の記録は、送信だけができ、運営者以外は読めないよう、アクセスを制限しています。

6. 保管期間と削除

アカウント情報と保存データは、利用者が当サービスを使っている間、または削除の申し出があるまで保管します。
アカウントの削除を希望する場合は、下のお問い合わせ先からご連絡ください。
法令で保管が必要なものを除き、速やかに削除します。
お問い合わせの内容は、対応に必要な間だけ保管し、不要になったら削除します。

7. 改定

このポリシーは、必要に応じて改定します。
改定したときは、このページで最終改定日とあわせてお知らせします。
